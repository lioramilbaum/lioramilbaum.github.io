## Featured work

- Article · Published Nov 10, 2026

  [Deploying Edge AI Across Heterogeneous Hardware](https://www.advantech.com/hi-in/resources/industry-focus/deploying-edge-ai-across-heterogeneous-hardware-from-compatibility-to-controlled-composition)

  **Problem:** edge AI runs on mixed hardware, and hardware that is merely compatible does not make a deployment predictable.

  **My contribution:** I wrote the article, which argues for controlled composition over compatibility.

  **Outcome:** published by Advantech.

- Project · Ongoing

  [projectmesh](https://github.com/lioramilbaum/projectmesh)

  **Problem:** before building a feature, you need to know how well it fits an existing codebase and what it would touch.

  **My contribution:** I'm building a Python CLI that assesses a feature request against a local repository, without modifying it, and writes a Markdown report on feature fit and likely implementation impact, using any OpenAI-compatible endpoint or the Claude Code CLI.

  **Outcome so far:** the source is public on GitHub.

- Experiment · Ongoing, Nov 2 – Dec 2, 2026

  [Software factory for this site](docs/qodo-software-factory-hackathon.md)

  **Problem:** can agents, rules and checks build and ship a real site, with evidence for every change?

  **My contribution:** I'm building that factory for lioramilbaum.com in Qodo's 30-day hackathon: the rules every change follows, the CI checks, and an agent runner that turns a labelled issue into a pull request.

  **Outcome so far:** each merged pull request gets a delivery doc with its evidence, and my daily submissions are linked from the hackathon page.
