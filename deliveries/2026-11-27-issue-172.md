# feat: add the story.py skeleton and its coverage-gated tests

**PR:** [#211](https://github.com/lioramilbaum/lioramilbaum.github.io/pull/211) · **Opened:** 2026-11-27

## Why

_From the PR description (author-written)._

Every later `story.py` task adds code, and each line needs CI coverage from the start (AGENTS.md rule 8).

## How

_From the PR description (author-written)._

- uv instead of pip and `setup-python`: a non-package uv project under `scripts/story-tests/` (`pyproject.toml`, `uv.lock` with all 119 release hashes, and `.python-version` 3.15.2).
- `uv sync --locked --no-build --managed-python` is the only network step.
- coverage runs with `-I --rcfile=/dev/null`, so later config files or modules can't weaken the gate.

Shown red once with the no-command test broken on purpose: [Check site run](https://github.com/lioramilbaum/lioramilbaum.github.io/actions/runs/46076621485) (failed at Test story.py on commit 04a970f).

## What

_From the PR description (author-written)._

- `scripts/story.py` (new, executable): `main(argv)` and a `__main__` entry point, the `REPO` constant, a refusal of Python older than 3.11 (exit 1), a usage error (exit 2, one stderr line) and a `fail` helper that exits 1. It has no commands yet.
- `scripts/story-tests/test_story.py` (new): unit tests for the usage line, the old-Python refusal, the 3.11 boundary, `fail`, `REPO` and the `__main__` entry point through `runpy`.
- `scripts/story-tests/pyproject.toml` (new): a non-package uv project that pins coverage.py by version.
- `scripts/story-tests/uv.lock` (new): the locked coverage.py with the sha256 of every release file.
- `scripts/story-tests/.python-version` (new): 3.15.2.
- `scripts/test-story.sh` (new, executable): syncs a temp venv with uv, runs the unittest suite under `coverage run --branch`, and fails unless `scripts/story.py` has 100% line and branch coverage.
- `.github/workflows/check-site.yml`: adds `astral-sh/setup-uv` pinned by SHA with uv 0.13.10 and its cache off, then a "Test story.py" step.
- `.gitignore`: ignores `__pycache__/`.
- `AGENTS.md`: Setup and Verify describe `scripts/test-story.sh`; rule 8 makes `scripts/story-tests/` test code and names `story.py` as code that needs tests; rule 11 lists `scripts/story.py`.

## Limitations

_From the PR description (author-written)._

- The old-Python refusal is tested by patching `sys.version_info`, not on a real 3.10 interpreter in CI.
- Python older than 3.7 fails with a `SyntaxError` instead of the refusal.
- Renovate's moves of the new pins are not exercised in CI.
- uv 0.13.10's download checksum comes from Astral's manifest at run time, because setup-uv v10.4.0 does not bundle it.
- `# pragma: no cover` can still exclude lines and is left to review.
