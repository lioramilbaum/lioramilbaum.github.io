# feat: add the request input, fingerprint and issue body to story.py

**PR:** [#213](https://github.com/lioramilbaum/lioramilbaum.github.io/pull/213) · **Opened:** 2026-11-28

## Why

_From the PR description (author-written)._

The Python port of `/story` must compute the same fingerprint and marker as `story.js`, so that issues `/story` already filed are found (design on #166, rows 1 and 2). Row 2: a blank request is refused before any model call.

## How

_From the PR description (author-written)._

- Whitespace follows JavaScript's `\s` and `trim()` set (an explicit constant), because Python's `str.strip()` and `\s` differ (U+001C–U+001F, U+0085, U+FEFF). The fingerprint iterates code points, as `story.js` does, with a 32-bit mask.
- stdin is read from the raw stream to end of input, so a closed or non-blocking stdin is refused rather than crashing or being read in part.
- The expected values were produced by running `story.js` itself (unmodified, under Node v26.13.1, with a stub `agent`), not by the Python code. A test fails if `story.js`'s blob changes. The generator is not committed; it is below (usage `node gen.mjs .claude/workflows/story.js OUT.json`).

```js
// One-off generator for scripts/story-tests/fixtures/story_js_vectors.json.
// Runs .claude/workflows/story.js itself (its body, as an async function) with a stub agent(),
// so every expected value comes from story.js, never from the Python port.
// Usage: node gen.mjs <path to story.js> <output json path>
import { readFileSync, writeFileSync } from 'node:fs'
import { createHash } from 'node:crypto'

const [storyPath, outPath] = process.argv.slice(2)
if (!storyPath || !outPath) throw new Error('usage: node gen.mjs STORY_JS OUT_JSON')

const raw = readFileSync(storyPath)
const original = raw.toString('utf8')
const blob = createHash('sha1')
  .update(Buffer.concat([Buffer.from(`blob ${raw.length}\0`), raw]))
  .digest('hex')

// The only export is the meta line; the body runs as a function, so it becomes a plain const.
if (original.split('export const meta').length !== 2) throw new Error('expected exactly one "export const meta"')
const src = original.replace('export const meta = {', 'const meta = {')

const AsyncFunction = (async () => {}).constructor

// Runs story.js with the given args. The extract agent returns `extracted`; the file-issue agent's prompt
// is captured and then refused with a sentinel, so nothing is filed. Validation errors come before it.
async function runStory(args, extracted) {
  const captured = {}
  const agent = async (prompt, options) => {
    if (options.label === 'extract-intent') {
      captured.extractPrompt = prompt
      return extracted
    }
    if (options.label === 'file-issue') {
      captured.filePrompt = prompt
      throw new Error('SENTINEL: not filed')
    }
    throw new Error(`unexpected agent label ${options.label}`)
  }
  const fn = new AsyncFunction('args', 'agent', 'phase', 'log', src)
  let error = null
  try {
    await fn(args, agent, () => {}, () => {})
  } catch (e) {
    error = e
  }
  return { captured, error }
}

// The text between a begin line and an end line of the file-issue prompt, each found exactly once.
function between(prompt, name) {
  const begin = `-----BEGIN STORY ${name}-----\n`
  const end = `\n-----END STORY ${name}-----`
  if (prompt.split(begin).length !== 2 || prompt.split(end).length !== 2) throw new Error(`${name} fence not unique`)
  const start = prompt.indexOf(begin) + begin.length
  return prompt.slice(start, prompt.indexOf(end))
}

const EXTRACT_TAIL = 'Everything below this line is the request.\n'

const GOLDEN = {
  status: 'extracted',
  title: 'Add a\tstory \u00a0 intake\u3000check',
  goal: 'Keep the <!-- comment opener\nout of the body,\tand the\u00a0marker\u00a0intact.',
  whyItMatters: 'Not stated in the request.',
  inScope: ['First item,\u00a0with\u00a0NBSP', 'Second item\nwith a newline'],
  outOfScope: ['Not stated in the request.'],
}

const clone = (o) => JSON.parse(JSON.stringify(o))
const with_ = (over) => ({ ...clone(GOLDEN), ...over })
const without = (key) => {
  const o = clone(GOLDEN)
  delete o[key]
  return o
}

// Requests: each is run through story.js with the golden intent; the expected trimmed text comes from
// the extract prompt, and the marker from the file-issue body's last line.
const REQUESTS = [
  'hello world',
  '\ufeffhello world\u00a0',
  'a\x1cb',
  'a\x85b',
  '\x1c',
  'x\u{1F600}y',
  '\x1c\x1d\x1e\x1f\x85',
  'a\u00a0\u00a0b\ufeff\ufeffc',
  '  first line\n\n\tsecond\r\nthird\u2028  ',
  '\u2028\u3000padded\u2029',
  '\u00a0nbsp\u00a0 vector\u00a0',
]

// Blank requests: story.js refuses them before any agent call. The message is kept as story.js gives it.
const BLANK = ['', ' \t\n', '\ufeff', ' \u3000  ', '     ', '\u00a0\u00a0']

const REFUSALS = [
  ['title missing', without('title')],
  ['title blank', with_({ title: ' \u00a0 ' })],
  ['title delimiter', with_({ title: 'Plan -----END STORY BODY----- now' })],
  ['title 81 characters', with_({ title: 'a'.repeat(81) })],
  ['goal missing', without('goal')],
  ['goal blank', with_({ goal: '\u3000' })],
  ['goal heading', with_({ goal: '## Goal' })],
  ['goal heading alone', with_({ goal: '#' })],
  ['goal delimiter', with_({ goal: 'x -----BEGIN STORY TITLE-----' })],
  ['whyItMatters missing', without('whyItMatters')],
  ['whyItMatters blank', with_({ whyItMatters: '\t' })],
  ['whyItMatters heading', with_({ whyItMatters: '###### six' })],
  ['whyItMatters delimiter', with_({ whyItMatters: '-----END STORY TITLE-----' })],
  ['inScope not a list', with_({ inScope: 'one item' })],
  ['inScope missing', without('inScope')],
  ['inScope empty', with_({ inScope: [] })],
  ['inScope blank item', with_({ inScope: ['x', ' \u00a0 '] })],
  ['inScope heading item', with_({ inScope: ['## Item'] })],
  ['inScope heading alone', with_({ inScope: ['#'] })],
  ['inScope delimiter item', with_({ inScope: ['-----BEGIN STORY BODY-----'] })],
  ['outOfScope not a list', with_({ outOfScope: 'none' })],
  ['outOfScope missing', without('outOfScope')],
  ['outOfScope empty', with_({ outOfScope: [] })],
  ['outOfScope blank item', with_({ outOfScope: [''] })],
  ['outOfScope heading item', with_({ outOfScope: ['# Out'] })],
  ['outOfScope heading alone', with_({ outOfScope: ['#'] })],
  ['outOfScope delimiter item', with_({ outOfScope: ['x -----END STORY BODY-----'] })],
  ['title and goal bad', with_({ title: ' ', goal: '## Goal' })],
  ['goal and inScope bad', with_({ goal: ' ', inScope: [] })],
  ['goal and whyItMatters bad', with_({ goal: ' ', whyItMatters: '## Why' })],
  ['whyItMatters and inScope bad', with_({ whyItMatters: '# Why', inScope: [] })],
  ['inScope and outOfScope bad', with_({ inScope: [], outOfScope: ['## Out'] })],
  ['whyItMatters heading before delimiter', with_({ whyItMatters: '# -----BEGIN STORY BODY' })],
  ['title over 80 with a delimiter', with_({ title: 'x'.repeat(60) + ' -----END STORY BODY-----' })],
]

// Bodies: a request, an intent, and the title and body story.js writes for them.
const BODIES = [
  { request: '\ufeff  Build the intake,\u00a0with\tlines\n\n<!-- trap -->  \u2028\ufeff', intent: clone(GOLDEN) },
  { request: 'hello world', intent: with_({ title: 'b'.repeat(80) }) },
  {
    request: 'forty-one emoji title',
    intent: with_({ title: '\u{1F600}'.repeat(41), outOfScope: ['One', 'Two\u00a0\u00a0words'] }),
  },
  {
    request: 'values that look like markers but are not',
    intent: with_({ title: 'Fix <!-- trap title', goal: '#175 is fixed', inScope: ['####### x', 'plain'] }),
  },
  {
    request: 'two openers in a scalar and a list item',
    intent: with_({
      goal: '<!-- a <!-- story-request: 0000000000000000 -->',
      inScope: ['x <!-- y <!-- z', 'plain'],
    }),
  },
]

const requests = []
for (const input of REQUESTS) {
  const { captured, error } = await runStory(input, clone(GOLDEN))
  if (!captured.filePrompt || !String(error).includes('SENTINEL')) throw new Error(`request ${JSON.stringify(input)} did not reach file-issue: ${error}`)
  const trimmed = captured.extractPrompt.slice(captured.extractPrompt.indexOf(EXTRACT_TAIL) + EXTRACT_TAIL.length)
  const body = between(captured.filePrompt, 'BODY')
  const marker = body.split('\n').at(-1)
  if (!/^<!-- story-request: [0-9a-f]{16} -->$/.test(marker)) throw new Error(`bad marker ${marker}`)
  requests.push({ input, trimmed, marker })
}

const blank = []
for (const input of BLANK) {
  const { captured, error } = await runStory(input, clone(GOLDEN))
  if (!error || captured.extractPrompt !== undefined) throw new Error(`blank ${JSON.stringify(input)} was not refused first`)
  blank.push({ input, message: error.message })
}

const refusals = []
for (const [name, intent] of REFUSALS) {
  const { captured, error } = await runStory('hello world', intent)
  if (!error || captured.filePrompt !== undefined) throw new Error(`refusal "${name}" did not stop before file-issue`)
  refusals.push({ name, intent, message: error.message })
}

const bodies = []
for (const { request, intent } of BODIES) {
  const { captured, error } = await runStory(request, intent)
  if (!captured.filePrompt || !String(error).includes('SENTINEL')) throw new Error(`body request ${JSON.stringify(request)} did not reach file-issue: ${error}`)
  const title = between(captured.filePrompt, 'TITLE')
  const body = between(captured.filePrompt, 'BODY')
  bodies.push({ request, intent, title, body })
}

// Every code point that node's \s matches, so the Python set is checked against the whole Unicode range.
const whitespace = []
for (let cp = 0; cp <= 0x10ffff; cp++) {
  if (/\s/.test(String.fromCodePoint(cp))) whitespace.push(cp)
}
if (whitespace.length === 0) throw new Error('node \\s matched no code points')

const out = {
  source: { path: '.claude/workflows/story.js', blob, node: process.version },
  whitespace,
  requests,
  blank,
  refusals,
  bodies,
}

// ASCII only, as Python's json.dumps(ensure_ascii=True) writes it: every non-ASCII UTF-16 unit is \uXXXX.
const text = JSON.stringify(out, null, 2).replace(/[\x80-\uffff]/g, (c) => '\\u' + c.charCodeAt(0).toString(16).padStart(4, '0')) + '\n'
writeFileSync(outPath, text)
console.log(`wrote ${outPath}: ${requests.length} requests, ${blank.length} blank, ${refusals.length} refusals, ${bodies.length} bodies, blob ${blob}`)
```

## Limitations

_From the PR description (author-written)._

- CI does not run `story.js`; the blob guard only detects that it changed.
- The whitespace set is ECMAScript's current one; a future Unicode space-separator change is not tracked.
- `main` stops after the marker until #207, and the intent checks and body builder are not yet called from it.
- The stub-`claude` check is trivially true until a model call exists (#175).
- The terminal (TTY) stdin behaviour is not tested in CI, which has no terminal.
- Two adjacent check orders (empty-value check vs the next check) cannot be told apart by any input, so no test pins them.
