# feat: assign the agent run's PRs and the docs PRs to the owner

**PR:** [#80](https://github.com/lioramilbaum/lioramilbaum.github.io/pull/80) · **Opened:** 2026-11-14

## Why

_From the PR description (author-written)._

The owner wants every PR the factory opens to be assigned to them, so it shows up in their own queue. Interactive sessions do this from memory, but the repo's own automation didn't. The agent run opened its PR with no assignee (PR #60 has none), and the delivery-doc skill's B7 opened docs PRs with none either.

## How

_From the PR description (author-written)._

- **Agent run.** `open_pr()` in `scripts/agent-run.sh` passes `--assignee "$owner"` to `gh pr create`. `AGENT_PR_TOKEN` already has pull requests and issues write, which assigning needs, so there is no new token and no new place a token appears.
- **Delivery-doc skill.** B7 opens a new docs PR with `--assignee lmilbaum`. On a reused docs branch, B7 always runs `gh pr edit <number> --add-assignee lmilbaum`. Adding an assignee who is already there is a no-op, so it doesn't check first. If the call fails, the skill stops and reports it rather than assuming the PR is assigned (rule 11). B6's byte-identical path used to jump straight to B8. It now skips only the commit and push, so the assignee step still runs.
- Both files are guarded paths, so the agent run can't make this change itself (residual risk 7). The run for this issue stopped at the guard stage with an empty change. This PR was made in the owner's session.

## What

_From the PR description (author-written)._

- `scripts/agent-run.sh`: `--assignee "$owner"` on the PR create call.
- `scripts/test-agent.sh`: case b (the happy path) also asserts that the logged `pr create` call has `--assignee lmilbaum`. With the flag removed from the runner, case b fails on that assertion (`1 agent test case(s) failed`). With it in place, the suite passes. CI already runs this file in `check-site.yml`.
- `.claude/skills/delivery-doc/SKILL.md`: B6 and B7, as above.
- `AGENTS.md`: the Setup paragraph says the run opens the PR "assigned to the owner".

Local runs: `bash scripts/test-agent.sh`, `bash scripts/test-delivery.sh` and `scripts/check-workflows.sh` pass.
